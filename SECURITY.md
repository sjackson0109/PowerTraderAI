# Security policy

## Reporting a vulnerability

Please don't report security vulnerabilities in public issues, pull requests or Discussions.

Report them privately through GitHub's private vulnerability reporting:
<https://github.com/sjackson0109/PowerTraderAI/security/advisories/new>
(or the **Security** tab → **Report a vulnerability**).

Include what you found, how to reproduce it, and the commit you tested. Never include real API keys,
secrets, private keys or account IDs: use made-up values.

Anything that could expose exchange credentials, or place or change an order the user didn't intend, is
especially important to report.
